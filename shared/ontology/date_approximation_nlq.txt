<query-notes>
For a DIAMM graph version with person-year observations, use GRAPH
diamm: (https://linkedmusic.ca/graphs/diamm/).
From the person follow diamm:personYear to one observation. On that observation
select diamm:dateProperty wdt:P569 for birth or wdt:P570 for death
(wdt: is http://www.wikidata.org/prop/direct/). Read diamm:sourceValue for the
original year cell and diamm:sourceApproximate for the original flag cell.
diamm:year is the parsed xsd:gYear when available. Keep this field optional
if the question includes unparsed source entries.

Use OPTIONAL { ?obs lm:approximate ?approximate } when listing dates.
This is the shared Boolean for one observed value across all databases.
Use the birth or death observation to select the right value. For true, report
“around 1850” if the year is 1850. For false, report “1850” at year precision. An
unbound flag means the source's approximation status is unknown. For a
question restricted to explicitly approximate birth years, require a typed
year and a true flag on the same birth observation. Direct person P569/P570
triples cover only explicitly non-approximate supported years. Keep differing
source observations separate. A circa flag supplies no day, range, probability
or information about the reliability of the answer.
</query-notes>
<ontology>
@prefix lm: <https://linkedmusic.ca/terms/preservation/> .
diamm:Person
	diamm:personYear	diamm:PersonYearObservation .
diamm:PersonYearObservation
	diamm:dateProperty	"wdt:P569 for birth or wdt:P570 for death" ;
	diamm:year	"optional xsd:gYear" ;
	diamm:sourceValue	"original year cell" ;
	diamm:sourceApproximate	"original approximation flag cell" ;
	lm:approximate	"optional Boolean qualifying this date" .
</ontology>
